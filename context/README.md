# Clay Current-State Context Pack

Updated: 2026-08-31

This directory is a Git-tracked operational context pack for ClayBot and other Clay workers.

It does **not** replace Clay product/design canon. It exists because the current Grok/Cursor GitHub identity can access `rroaam/clay-ops` but cannot currently access the private canonical repository recorded by recent source receipts as `claylife/clay-engine`.

## Read order

1. `CURRENT_STATE.md` — what is actually active now
2. `ACTIVE_PRIORITIES.md` — current team work queue
3. `RECENT_REVIEW_LANES.md` — verified recent branches, commits, previews, and QA receipts
4. `DESIGN_EXECUTION_CONTEXT.md` — current AI design execution bridge and source rules
5. `SOURCE_INDEX.md` — live source pointers across Drive, Slack, GitHub, Vercel, and Figma status
6. `REPO_ACCESS_GAP.md` — exact private-repo access issue blocking full implementation

## Authority rule

This pack is a **pointer and reconciliation layer**, not canon.

If `claylife/clay-engine` becomes accessible, its current authority files outrank this directory. Recent explicit human approvals also outrank summaries here.

Do not silently copy these summaries back into product canon.

## Current visual thesis

Clay is quiet, premium, evidence-led, and human. It should feel composed rather than decorated: neutral fields, strong typography, cinematic real-life photography, hairlines, measured spacing, negative space, and meaningful data visualization.

Avoid generic wellness, luxury-spa, generic SaaS, loud chrome, decorative gradients, glow, glass, and equal-box dashboard composition.

## Current global grounds

- Canvas: `#FBFAF4`
- Paper: `#EBE7DF`
- Off-black: `#121110`
- Card: `#FCFBF8`
- Ink: `#1B1917`

Never use pure white/black or green/lime/orange as general UI chrome.

## Five Elements order

Fuel → Heart → Brain → Body → Blood

Element color is used only when that element is actually the subject.

## Typography

- Geist for display/headings/body/nav/controls
- Geist Mono for labels/metadata/steps/folios/data
- use `ClayMark` rather than typesetting the logo
